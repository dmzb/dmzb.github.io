For problems 1, 2, and 3, let $A, B$ and $C$ be sets and let $f \colon A \to B$ and $g \colon B \to C$ be functions.
\\

When giving a disproof, \textbf{please give a counterexample} (otherwise no credit will be given for the problem). 


 \begin{enumerate}
 \item Prove or disprove: If $g\circ f$ is an injection, then $g$ is an injection.
   

 \item Prove or disprove each of the following. 
 \begin{enumerate}   
 \item If $g\circ f$ is a surjection, then $f$ is a surjection.
 \item If $g\circ f$ is a surjection, then $g$ is a surjection.
 \end{enumerate}
 
\item Let $A$ and $B$ be sets and let $f \colon A \to B$ and $g \colon B \to A$ be functions. Prove that if $g \circ f$ and $f \circ g$ are bijective, then so are $f$ and $g$.


  
\item We say that a function $f\colon \mathbf{R} \to \mathbf{R}$ is \textbf{increasing} if for all $x_1,x_2 \in \mathbf{R}$, if $x_1 < x_2$, then $f(x_1) < f(x_2)$.\\

We say that a function $f\colon \mathbf{R} \to \mathbf{R}$ is \textbf{decreasing} if for all $x_1,x_2 \in \mathbf{R}$, if $x_1 < x_2$, then $f(x_1) > f(x_2)$.\\  

  Let $f \colon \mathbb{R} \to \mathbb{R}$ and $g \colon \mathbb{R} \to \mathbb{R}$ be functions. Suppose that $f$ and $g$ are both decreasing. Prove that $g \circ f$ is increasing.
 \end{enumerate}
