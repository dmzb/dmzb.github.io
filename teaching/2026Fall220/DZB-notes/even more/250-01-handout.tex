1. Which of these are \textbf{statements}? (I.e., for which of these sentences is `true or false' meaningful?)
\vspace{10pt}
\begin{enumerate}
\item (Statement) Today it is raining.
\item (not) What is your name?
\item (S) Every student in this class is a math major.
\item (S) $2 + 2 = 5$.
\item (open statement, but not a statement) $x + 1  > 0$.
\item (False statement) $\forall x \in \mathbf{R}, x + 1  > 0$.
\item (To disprove a for all statement, just give an example where it is false)
\item (true statement) $\exists x \in \mathbf{R}$ such that  $x + 1  > 0$.
\item to prove an "exists" statement, just give an example where it is tru.
\item $x^2 + 1  > 0$.
\item If it is raining, then I will wear my raincoat.
\item Whenever it is raining, I will wear my raincoat.
\item it is raining $\Rightarrow$ I will wear my raincoat
\item If $P$ then $Q$; $P \Rightarrow Q$; Whenever $P$ is true, $Q$ is also true.
\item Give me that.
\item (not) This sentence is false.
\item If $x$ is a real number, then $x^2 > 0$.
\end{enumerate}
\vspace{20pt}

2. Which of these are true? 
\vspace{10pt}
\begin{enumerate}
\item (F) Every student in this class is a math major and a human being. (False because "Every student in this class is a math major" is false)
\item (T or F) Every student in this class is a math major or a human being.
\item (T or F) $2 + 2 = 5$ or  $1  > 0$.
\item (T or F) If $x$ is a real number, then $x^2 \geq 0$.
\item (T or F) If $x$ is a complex number, then $x^2 \geq 0$.
\end{enumerate}
\vspace{20pt}

3. Write the negations of the following. (The negation of a statement is the statement with the opposite truth value.)
\vspace{10pt}
\begin{enumerate}
\item $2 + 2 = 5$; $2 + 2 \not = 5$
\item $1  > 0$; $1  \leq 0$
\item $2 + 2 = 5$ or  $1  > 0$; $2 + 2 \not = 5$ and  $1  \leq 0$.
\item $P \wedge Q$ (and)
\item $P \vee Q$ (or)
\item $\neg$ means negation
\item $P \vee Q$ (or); $\neg (P \vee Q) = \neg P \wedge \neg Q$
\item Every student in this class is a math major.
\item There is at least one student in this calss who is not a math major.
\item Every student in this class is a math major or a human being.
\item $\neg(\forall x, P(x)) = \exists x$ such that $\neg P(x)$
\item If $x$ is a real number, then $x^2 > 0$. ($x = 0$ is a counterexample)
\item $\neg (P \Rightarrow Q) = P \wedge \neg Q$
\end{enumerate}
\vspace{20pt}

4. Prove the following using truth tables.
\vspace{10pt}
\begin{enumerate}
\item $P \wedge(  Q\vee R) = (P\wedge Q) \vee (P \wedge R)$,
\item $(P \vee Q) \vee R = P \vee (Q \vee R)$. (We thus write $P \vee Q \vee R$ for both.)
\item \label{enum:distNeg} $\neg (P \vee Q) = \neg P \wedge \neg Q$,
\item $\neg (P \wedge Q) =$ (make a guess similar to problem \ref{enum:distNeg}),
\item $\neg (\neg P) = P$.
\end{enumerate}
